# Provider icons

The settings and playlist migration screens display locally bundled brand silhouettes inside an identical 22%-rounded square. The backgrounds are presentation colors, not downloaded application icons. Images are not loaded from third-party domains at runtime.

- NetEase Cloud Music: [Simple Icons SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/neteasecloudmusic.svg).
- Bilibili: [Simple Icons SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/bilibili.svg).
- YouTube Music: [Simple Icons SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/youtubemusic.svg).
- QQ Music: [public vector logo](https://cc0.cn/logo/svg-q-3sy2bd7sv7zh.html), music-note silhouette only.

The logos and trademarks remain the property of their respective owners. Displaying them identifies supported services; it does not imply any affiliation or endorsement. The Simple Icons artwork is distributed under CC0; trademark rights are separate. Respect each provider's branding requirements if these assets are redistributed outside this app.
