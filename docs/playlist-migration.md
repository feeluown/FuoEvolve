# 歌单迁移开发约定

用户流程：选择歌单 → 选择目标平台 → 自动找歌 → 核对匹配 → 选择目标歌单 → 迁移 → 查看记录。

界面使用「正在找歌」「检查匹配」「正在迁移」「继续迁移」「重试失败歌曲」等简短文案。

## 恢复要求

- 保存来源歌曲快照、匹配候选、用户选择、目标歌单 ID 和每首歌写入状态。
- 分页读取、匹配、创建歌单、添加歌曲每个步骤均落盘；中断后只重做未完成部分。
- 创建歌单请求结果不明确时，不自动再次创建；请用户确认/选择已经创建的歌单。
- 添加歌曲结果不明确时，先核对目标歌单，不能盲目重发。
- 失败保留任务及成功项目，可重试失败歌曲；不删除或修改来源歌单。
- 后台能力受平台限制：Android 需持久任务调度，桌面运行期间可执行，iOS 挂起时不承诺持续运行，均需能恢复。

## 实现阶段

1. 任务模型、检查点与恢复测试。
2. 对接音源搜索/歌单读写并实现批量写入能力探测。
3. 实现六个页面和各平台持久后台调度、端到端验证。

以上为交付约束，不代表功能已全部实现。
