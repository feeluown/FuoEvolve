# Fuo Replacement Lite v1

This Android-only model asset is the fixed-optimization ORT-format conversion
of the INT8 ONNX export of `BAAI/bge-small-zh-v1.5` published by
`Xenova/bge-small-zh-v1.5` at commit
`75c43b069aac4d136ba6bc1122f995fedcfd2781`.

- Base model: https://huggingface.co/BAAI/bge-small-zh-v1.5
- ONNX export: https://huggingface.co/Xenova/bge-small-zh-v1.5
- Base-model license: MIT
- Model SHA-256: `ccf14ca4aea30d29ad108a167d0c2ad1b521ab2ddac0e41038034167409ad382`
- Vocabulary SHA-256: `45bbac6b341c319adc98a532532882e91a9cefc0329aa57bac9ae761c27b291c`

FuoEvolve combines its semantic similarity with deterministic song identity,
duration and version rules. The bundled base model has not itself been trained
on private user choices; personalization is stored only in the app's local
preference head.
